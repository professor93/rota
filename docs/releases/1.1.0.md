## rota 1.1.0

### Changed for people coming from 1.0.6

- **The reply is the answer alone.** `blocks` and `ask` no longer appear unless asked for. Every reading is opt-in through `--with` on the command line (repeat it or separate with commas) and `"with"` over HTTP: `blocks`, `ask`, `raw`, `deltas`, `code`, `files`, `timing`, `quota`, `tools`, `stats`, `argv`, `plain`, `links`, `account`, `hooks`, `subagents`, `suggestions`, `stderr`. An unknown reading is refused by name.
- **A failed run keeps its `result` empty.** The reason stays in `stderr`, where the CLI put it; it is no longer copied into `result`. `--with stderr` restores the old reading.
- `--partial` and `--events` on `run` are now `--with deltas` and `--with raw`.
- **Every claude account runs in a mirror of `~/.claude`** kept at `~/.rota/homes/claude-<id>`: symlinks to your own settings, memory, skills, plugins, history and conversations, refreshed on every launch. Nothing looks different, but Claude Code's background daemon is now per account and inherits that account's token, so background sessions and the agent view are billed to the account that opened them. `rota set <id> --config DIR` still opts into a fully separate directory. If the mirror cannot be built, rota says so and runs as before.

### New

- **Talking to a running run.** `rota run … --input` keeps a run open and reads more messages from stdin; `rota send <run> "…"` reaches it from another terminal, with `--steer`, `--interrupt` and `--close`. Over HTTP, `"input": true` and the `/v1/runs` endpoints: messages and interrupts by id, reattaching with replay, a grace period, heartbeats. Over a WebSocket, `/v1/ws`, `/v1/accounts/{id}/ws` and `/v1/runs/{id}/ws` carry a run both ways with acknowledgements; the playground can talk back. The library has `Session`: `Start`, `Send`, `Steer`, `Interrupt`, `Close`, `Notices`.
- **Streaming says more.** Text and thinking arrive as deltas when asked, tool events carry their input, usage events carry numbers, and `done` carries turns, cost and totals.
- **Where conversations live is a setting.** `rota set <id> --sessions shared|own|<dir>`, shared by default; the same over HTTP as `sessions`, confined exactly as `config_dir` is. Claude Code's live-session registry stays each account's own in every mode.
- **`rota list --sessions` shows each conversation's name**, the one Claude Code's own picker shows.
- **The CLI is told which account it runs as**: `ROTA_PROVIDER`, `ROTA_ACCOUNT_ID` and `ROTA_ACCOUNT` in its environment, for status lines and hooks.
- **A dead account says why**: the provider's refusal is kept and shown beside "re-auth needed".
- `rota list` is a framed table: one usage window per line, `#` for the place in the rotation, `CLI` for the provider.

### Platforms

Linux and macOS are the supported targets. Windows binaries are built and smoke-tested; features that need symlinks fall back with a warning there.
